BullBull Unpacker 1.1.0
==============================

使用方法
----------------------
将整个文件夹放置在具有写入权限的位置。
双击 BullBull Unpacker.exe 启动程序。
将压缩包或文件夹拖入窗口，点击绿色的“开始”按钮。
如需使用右键菜单，请进入“设置”并点击一次“安装到右键菜单”。此后，在文件、文件夹或文件夹空白处点击右键，均可看到“添加到 BBU 解压列表”。

数据存储
----------------------
config.json 设置
密码本.txt    已记住的密码，每行一个。可以直接用记事本编辑；也可以用密码本页的“批量导入…”从一个 txt 追加；
                    文件中「以上是工具说明」和「密码从这里开始」之间是备注区，可以随意编辑；
                  「密码从这里开始」以下每行均视为密码，包括以 # 开头的内容。
                    如果密码首尾包含空格、制表符等特殊字符，为避免文本处理时丢失，程序会将该密码保存为 \B64: 开头的 Base64 编码行。读取时会自动还原，无需手动处理。
logs\ui.log 启动与出错日志
logs\run.log 完整操作流水

整个文件夹可直接复制迁移，数据会随文件夹一并保留。
如果该位置没有写入权限（例如 C:\Program Files\ ）数据将自动改存至 %APPDATA%\BullBullUnpacker，实际存储位置会在设置页面中注明。

需要了解的事项
----------------------
解压加密的 RAR 或 RAR5 文件需要系统中已安装 WinRAR，需用户自行安装并确保已获得合法授权，本项目不包含、分发和修改其任何组件。
apk / iso / jar 等类型默认不解压，如需解压，请在“设置 → 不处理的文件类型”中删除对应扩展名。
本程序全程本地运行，不包含任何网络通信组件，不会上传和收集任何信息。
密码本为明文存储，未进行任何加密，请用户谨慎保管。
