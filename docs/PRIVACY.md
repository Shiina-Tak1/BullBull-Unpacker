# 隐私政策 / Privacy Policy

BullBull Unpacker 是一个完全在本地运行的 Windows 应用程序。

## 中文

- **不收集任何信息。** 程序不包含任何网络通信组件，不向任何服务器发送数据，也没有遥测、
  统计或崩溃上报。
- **不读取与任务无关的文件。** 程序只访问用户通过拖放、右键菜单或命令行明确指定的路径，
  以及它自己的数据目录。
- **数据只存在本机。** 配置（`config.json`）、密码本（`密码本.txt`）与日志（`logs\`）都
  保存在程序自己的目录下，不上传，也不备份到任何地方。
- **密码本为明文存储。** 密码本没有加密，任何能读取该文件的程序都能看到里面的密码，
  请自行保管。
- **卸载即删除。** 便携版除当前用户的注册表（右键菜单项）外不写任何系统位置；删除程序
  目录即完成卸载，右键菜单可在程序设置里移除。

## English

BullBull Unpacker is a Windows application that runs entirely on the local machine.

- **No data collection.** The application contains no network component. It sends no data to
  any server and includes no telemetry, analytics or crash reporting.
- **No access beyond the task.** It only touches the paths the user explicitly provides through
  drag and drop, the context menu or the command line, plus its own data directory.
- **Data stays on the machine.** The configuration (`config.json`), the password book
  (`密码本.txt`) and the logs (`logs\`) are stored next to the application. Nothing is uploaded
  or backed up anywhere.
- **The password book is plain text.** It is not encrypted; any program that can read the file
  can read the passwords in it. Keep it safe.
- **Uninstalling removes everything.** The portable build writes nothing outside its own folder
  and the current user's registry (the context menu entries), which can be removed from the
  application's settings.

---

This program will not transfer any information to other networked systems unless specifically
requested by the user or the person installing or operating it.
